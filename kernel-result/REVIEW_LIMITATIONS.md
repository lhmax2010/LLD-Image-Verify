# Review limitations

## 证据范围

- 旧发布 QB 的 kdbus 中间链接证据保持 `BFD_PATH_POSSIBLE`。新发布 QB 中间与最终链接各为 E3。E4 属于 Phase 12 本地受控作业。原始执行痕迹中确认的路径、完整 argv、工具摘要和退出状态保留。
- 目标为 RPi4 ARMv7l 非 RT。A/B 共用带已公布差异的恢复 Tizen 环境和较早 BFD 2.43 加速载体。Phase 12 两种基准与 Phase 13 八核补测各有独立配置。墙钟与链接进程 RSS 适用各自输入和测量条件。
- Phase 14 的证据通过设备文件与发布 RPM 成员摘要绑定，运行主内核从发布启动 RPM 的 raw Image notes 和 banner 建立关联。设备活动 RPM DB 中的包所有权和 journal 完整内容不可得。功能用例未执行，运行内存未量测。产品合入和 Kernel Owner 代价认可待完成。

## 公开归档范围与缺口

- 发布副本针对公网脱敏，原始文件在工作区原封存档。内部设备地址和构建/工作站名称用一致化标签替换，个人目录、非公开邮箱、网卡地址、设备启动实例 UUID 和认证形式 URL 经脱敏。SDB 采集脚本要求调用者提供授权 serial。保留发行版标识、已发布提交、公共源码引用、工具版本、完整目标命令参数和技术结论。
- 目标 E4 exec 跟踪保留实际 executable、argv、进程退出与对应对象摘要。过程环境数组、HTTP 头部、认证辅助工具和整个构建追踪排除。公开的设备启动日志保存准入、boot 与 kdbus 相关原始行的脱敏摘录，保留 548 行原始观察范围及分类检查结果。非目标型系统日志、可能涉及产品状态的详情保留在本地。
- 完整系统镜像、RPM、工具链二进制、模块/中间 ELF、完整本地源码工作树和大型证据包留在本地。发布工件通过公开来源、确切路径和原始 SHA-256 识别。本仓库支持独立核对实测记录、统计与决定，重新构建或重新链接需准备对应依赖和二进制输入。历史报告中未共布的本地引用由本页及链接缺口清单标识。
- 调试与重定位数据保留可审查的关键完整实例。冻结中间 ELF 对比 JSON 仅压缩文本表示，保持其 JSON 内容。重复 ELF 对比、重复便携树、编译缓存和非目标输出有记录地排除。历史文本保留原有行尾或补丁上下文空白，目录内 Git 属性用于保留这些归档字节。同字节资料在保留一个规范路径后标记去重，独立阶段脚本和 Makefile 因相对路径或复验入口需要可各自保留。
- 完整本地数据的原始工件摘要可能出现在引用或构建记录里。公开仓库自身的校验以 [SHA256SUMS](SHA256SUMS) 为准，它对应脱敏之后发布的实际字节。
